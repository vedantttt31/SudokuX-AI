# SudokuX — Intelligent Constraint-Driven Sudoku Solver

SudokuX is an educational AI project that formulates Sudoku as a Constraint Satisfaction Problem (CSP). It demonstrates backtracking search, MRV, Degree heuristic, LCV value ordering, forward checking, AC-3 arc consistency, algorithm benchmarking, difficulty estimation, and a replayable reasoning trace through Streamlit.
App link : https://sudokux-ai-eearwamkbb5xbkfljqekbq.streamlit.app/

## Features

- **CSP model:** 81 variables, domains `{1,...,9}`, and row/column/3×3 inequality constraints.
- **Search strategies:** basic backtracking, MRV, Degree tie-breaking, LCV value ordering, forward checking, AC-3, and combined configurations.
- **Input validation:** board shape, cell values, and duplicate clues in rows, columns, and boxes.
- **Explainable trace:** records variable selection, candidate values, tentative assignments, contradictions, and backtracking with board snapshots. The UI replays these events one at a time.
- **Difficulty estimate:** uses a fixed reference solver (AC-3 + MRV + Degree + LCV + FC) and reports initial domains plus search effort. Labels are project-defined estimates, not official Sudoku ratings.
- **Algorithm Battle:** runs all eight configurations on the same puzzle and compares measured counters and repeated runtime.
- **Experiments:** reproducible multi-puzzle benchmark CSV and plots.
- **Demo puzzle generation:** creates a valid patterned completed grid and removes cells. It guarantees a valid completion exists, but does not guarantee uniqueness.

## Run locally

Python 3.10 or newer is recommended.

```bash
# Windows PowerShell
py -m venv .venv
.venv\Scripts\Activate.ps1

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
python -m unittest discover -s tests -v
streamlit run app.py
```

## Run experiments

From the project root:

```bash
python -m experiments.benchmark
python -m experiments.plot_results
```

The benchmark writes `experiments/results/benchmark_results.csv`; charts are written to `experiments/results/plots/`. Results are generated by the code and should be regenerated on the machine/environment used for the final report. Runtime is hardware-dependent.

## Deploy on Streamlit Community Cloud

1. Push this project to a GitHub repository (do not upload `.venv`).
2. Open Streamlit Community Cloud and create an app from that repository.
3. Set the main file path to `app.py`.
4. Deploy. Streamlit installs dependencies from `requirements.txt`.

No API keys or secrets are required.

## Important modelling note

The binary CSP encodes each Sudoku peer relationship as `Xi != Xj`. AC-3 enforces arc consistency over these binary constraints. This is not the same as a specialized global `AllDifferent` constraint propagator; therefore AC-3 alone does not perform every possible Sudoku deduction. Backtracking remains the complete search procedure.
